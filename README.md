# Nanopod Vault

Mobile-first playlist page for **official** stream links (SoundCloud, Spotify, YouTube).

- Paste a link → embeds the provider’s official player
- Saves list in `localStorage` on that device/browser
- No file uploads, no ripping, no proxy

## Deploy on GitHub Pages

1. Create a new repo named `nanopod-vault` (or any name).
2. Upload `index.html` (this folder’s file) to the repo root.
3. Settings → Pages → Source: Deploy from branch `main` / `/ (root)`.
4. Open `https://YOURUSER.github.io/nanopod-vault/`

## Use inside Nanopod

Point the in-game browser at your Pages URL:

```text
https://YOURUSER.github.io/nanopod-vault/
```
